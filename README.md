# Corporate Bond Credit Risk Forecasting System
**PG&E 3.85% Senior Notes | 2016–2023**

## Project Overview

Developed an end-to-end corporate bond credit risk forecasting system analysing Pacific Gas & Electric (PG&E) across pre-crisis, Chapter 11 bankruptcy, and post-emergence recovery periods.

Integrated macroeconomic indicators (FRED), market data (Yahoo Finance), and SEC EDGAR financial disclosures using point-in-time data alignment to minimise look-ahead bias.

Applied time-series econometrics and machine learning to analyse credit spread dynamics, volatility clustering, financial distress, and predictive risk indicators. Implemented ARIMAX, GARCH, cointegration analysis, and Logistic Regression/Gradient Boosting models with chronological out-of-sample evaluation.

## Technology Stack

- **Programming:** Python
- **Data Processing:** pandas, NumPy
- **Time-Series & Econometrics:** statsmodels, arch
- **Machine Learning:** scikit-learn
- **Data Sources:** FRED, Yahoo Finance, SEC EDGAR
- **Visualisation:** Matplotlib
